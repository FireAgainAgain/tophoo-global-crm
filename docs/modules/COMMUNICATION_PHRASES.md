# 沟通话术

入口：**CRM → 工具 → 沟通话术**。

- 工具栏“导出全部 PDF”导出当前项目所有分类的全部话术，不受搜索、分页和当前场景筛选影响。PDF 按分类、场景顺序分组，左侧书签目录按分类 → 场景 → 话术三级导航，并请求阅读器打开时显示目录面板，包含未分场景话术、原文高亮块、中文翻译和页码；只读用户也可导出，当前分类为空也能导出其他分类内容；项目无话术时不可导出，旧分类导出接口已移除。

- 按“分类 → 场景模块 → 话术”组织。左侧仅显示实际分类，默认打开第一个分类；选择分类后，右侧顶部仅显示自定义场景，以及有未归属话术时才出现的“未分场景”按钮；没有“全部场景”选项。切换分类时优先进入“未分场景”，没有未归属话术时进入首个场景；场景可新增、改名、排序或删除。
- 每条话术填写分类、场景、原文与翻译；编辑时可选择具体场景或保留“未分场景”；可在话术编辑窗口直接新增场景，保留已填写的正文。历史未归属场景的话术仍可从所属分类下的“未分场景”查看。在场景内新增话术会自动带入分类和场景，编辑时切换分类会重置场景选项。翻译可留空，搜索覆盖当前分类和场景内的原文、翻译、分类及场景名称，正文命中词会高亮。
- 右侧以独立卡片展示原文及下方中文翻译；原文始终使用浅灰高亮块和左侧竖线，列表及详情保持一致，突出“复制原文”。只展示当前分类与所选场景的话术，不在每条正文内重复分类或时间。
- 日常操作栏提供复制与编辑，点击工具栏“调整顺序”后再显示上移和下移；手机端操作栏放在正文下方；顺序会保存。分类或场景筛选下调整对应范围内的顺序，不影响其他范围内话术的相对顺序；搜索时先清空关键词再排序。
- 列表在固定高度内独立滚动，搜索和新增按钮保持可见。
- 点击话术查看全文；编辑使用独立的大窗口，关闭未保存内容时提醒。默认复制按钮只复制原文，详情中也可单独复制翻译，提示不推动列表。保存及排序后的列表刷新保留滚动位置；修改话术归属后自动切到目标分类和场景。分类与场景菜单跟随触发按钮定位，点击外部、按 Esc 或滚动时收起。
- 删除含话术的场景时，必须先选择同分类的其他场景接收话术；没有可用目标时，先新增场景或移出话术。空场景可直接删除。删除含话术的分类时必须选择其他分类接收内容；场景一并迁移，目标分类下同名场景自动合并。最后一个分类有内容时不能直接删除。
- 按项目共享，与知识库内容分开存储。支持只读与可编辑权限，只读用户可搜索、查看和复制。
- 首次安装时，已有知识库访问权限沿用到本模块，并保留原来的读写级别；之后可在角色权限中单独修改。
- 启动时自动建表并为已有话术增加可空的 `scene_id`，保留原文、翻译和顺序。完整数据库备份应包含 `crm_phrase_categories`、`crm_phrase_scenes` 和 `crm_communication_phrases`；项目删除会清理所属分类、场景与话术。

验证：`tests/test_communication_phrases.py`、`tests/communication_phrases_ui.cjs`、`tests/phrase_scenes_ui.cjs`、`tests/phrase_experience_ui.cjs`。界面测试使用隔离数据，不写入真实话术。
