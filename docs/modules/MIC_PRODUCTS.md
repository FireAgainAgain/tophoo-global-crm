# 产品记录和 MIC 发布助手

在「SEO → 建站 → 产品记录」维护产品。产品记录可以填写产品编号、名称、分类、图片、网站 SEO 名称和描述，以及中文产品内容。

## MIC 发布

有 MIC 编号范围的产品进入发布助手。编号使用数字，例如 `101–105`。可以填写发布进度，为范围内的各编号维护名称、核心关键词和优化建议。标记已优化后，对应优化建议会退出待办。只有编号规则允许的范围才能保存。

## 社媒文案

每个产品可以保存 Facebook、Instagram、LinkedIn 和 YouTube 的中英文文案。YouTube 另外维护视频标题和标签。联系方式可在编辑面板填写。发布标记用于内部登记。

## 存储与备份

产品记录、文案及上传图片保存在数据库中。迁移时使用 SQLite 安全备份或对应数据库导出方式。演示产品由演示脚本生成。
