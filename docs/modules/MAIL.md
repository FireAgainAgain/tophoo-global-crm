# 邮箱配置

“系统 → 邮箱配置”已纳入工作区与项目角色权限：无权限隐藏入口并拒绝接口访问；只读可查看本人的配置摘要和发送记录；可编辑允许维护配置、测试连接和发送测试邮件。开发信发送还需对应项目的线索编辑权限。邮箱授权不会允许查看他人的配置或发送记录。

入口：**系统 → 邮箱配置**。每个用户配置一个自己的发件邮箱，跨项目使用；其他成员及管理员不会通过此接口读取你的配置或发送记录。

## 配置与测试

未配置时直接填写；保存后默认显示邮箱、服务器、加密方式与测试状态。点击“编辑配置”再修改，取消会还原已保存内容。编辑时不测试旧配置，签名默认折叠，可只读预览。

1. 从邮箱服务商获取 SMTP 服务器、端口和授权码／客户端专用密码，开启 SMTP 服务。
2. 填写发件人名称、邮箱、登录账号及加密方式，保存配置。支持 SSL/TLS、STARTTLS，不支持明文登录和 OAuth 登录。
3. 点击“测试连接”：只验证 TLS 和登录，保存结果及测试时间。
4. 需要验证实际发送时，点击“给自己发送测试邮件”，确认后发送到自己的发件邮箱。

授权码加密保存，不在页面回显；留空保留原值，输入新值替换。“显示／隐藏”只作用于本次输入。修改连接信息后，旧测试结果自动失效。签名选填，可在发送预览中按需添加。

## 发送开发信

线索详情 → 开发信 → 填写收件人、标题和正文 → **发送邮件** → 核对预览 → **确认发送**。

- 进入发送预览前保存草稿，进入预览本身不发送。
- 可选择该公司的不同联系人，也可手动填写单个收件邮箱。
- 最多 5 个附件，总大小不超过 10 MB；附件只随本次邮件发送，不保存为项目文件，记录中保留文件名、大小及校验值。
- 服务器接受后自动生成沟通概要；线索状态保持原样，后续由用户手动修改。外部发送的邮件仍需手动补录，系统发送的邮件不必重复补录。

## 发送结果

在邮箱配置下方查看本人最近 50 次发送的正文、附件信息、时间和结果。

| 结果 | 含义与操作 |
| --- | --- |
| 服务器已接受 | SMTP 服务器接受了邮件；不等于送达或已读，不自动重发 |
| 发送失败 | 登录、地址或服务器明确拒绝；修正后可确认重试 |
| 处理中／结果待核实 | 网络中断或结果未知；先查询发送记录、邮箱服务器记录或请收件人核实，勿直接重发 |

重复提交同一发送请求不会再次投递。没有投递回执、已读跟踪或收信功能；当前不自动写入邮箱服务器的“已发送”文件夹，因此不能保证在 Foxmail 的“已发送”中看到系统发出的邮件。

## 部署与备份

服务器需能连接邮箱服务商的公网 SMTP 端口。仅允许公网 SMTP 地址；不连接本机或内网服务。

建议在 `.env` 中配置稳定的 `MAIL_ENCRYPTION_KEY`，并与数据库一起备份：

```powershell
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

未设置该项时，密钥从 `JWT_SECRET_KEY` 派生。更换所使用的加密密钥后，需重新输入邮箱授权码。不要将 `.env` 或授权码提交到公开仓库。


### 多邮箱管理（2026-10-30）
- 保留原个人邮箱配置，新增 `user_mail_accounts` 存储额外邮箱；每个邮箱独立保存连接、加密授权码、签名和测试结果。
- 配置页使用左侧邮箱列表、右侧配置详情，支持新增、切换、编辑、删除和默认发件邮箱；历史发送记录保留。
- `GET/POST /api/mail/accounts`、`PUT/DELETE /api/mail/accounts/{account_id}`、`POST /api/mail/accounts/{account_id}/default` 按用户隔离。原配置以 `account_id=0` 兼容访问。
- `GET /api/mail/configuration` 默认读取默认邮箱，指定 `account_id` 可读取其他本人邮箱；测试连接和测试邮件也接受邮箱选择。
- 开发信发送预览先选择发件邮箱，发送表单传 `account_id`，服务端重新验证归属；开始逐人发送后锁定邮箱，发送幂等校验包含所选邮箱。
- 在发送预览添加签名后切换邮箱，会移除本次预览添加的签名，可重新添加所选邮箱的签名；草稿中手工写入的内容仍需确认。
- 不自动测试连接或发送邮件；所有集成测试拦截 SMTP 和实际发送，新增邮箱需要用户填写真实连接资料。
