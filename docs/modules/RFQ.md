# 询价单

更新：2026-11-01。

## 入口与列表

在客户列表中点击该公司的询价数量、编号或状态，进入该客户的单据工作区。顶部显示客户名、询价单 / 报价单切换和数量，返回按钮回到客户列表。

客户工作区只展示该客户且属于当前用户的询价单，不再常驻显示搜索框、状态统计、来源或归属筛选。若从某个状态或编号进入，会显示可移除的条件提示；移除条件后查看该客户全部询价。

常用操作仅保留刷新和新建。桌面列表显示编号、询价日期、来源和状态，按编号自然倒序排列；手机使用卡片，状态可直接修改。单据不超过一页时隐藏分页；多页时可翻页，默认 20 条，可调整每页数量。

## 新建、编辑与详情

客户工作区新建询价时，自动关联当前客户并锁定客户选择。可填写编号、日期、来源、状态、对接联系人、需求字段和跟进详情。编号留空仍使用系统默认自动编号；已有 V/v 编号已按业务要求补入 26，未修改自动编号规则。

点击编号或记录查看详情，底部仅保留删除和编辑；删除前确认。没有任何询价、需求模板或汇总导出功能，Excel、PDF、Markdown 导出接口均已移除。

询价联系人保存快照，避免客户改名、换主联系人或联系人删除导致历史对接资料丢失；客户公司资料按当前档案显示。切换联系人时建立新快照。跟进详情用于内部记录，保留旧产品编号等历史内容。

需求内容支持多条标题和正文；删除字段后清理其参数备注。保存失败保留表单输入；未保存离开有提醒。支持 Ctrl / ⌘ + S、Esc 关闭及键盘焦点返回。

## 状态与权限

状态为待处理、推进中、已报价、已成交、已关闭，允许按实际业务回退或跳过。旧“需求确认中”“报价准备中”展示为推进中，旧“沟通失败”展示为已关闭。状态修改使用专用接口，只修改状态，不覆盖需求内容、联系人或跟进详情。

功能仍由 `rfq` 模块权限控制；写操作要求写权限。接口按项目和单据归属检查访问，客户工作区额外按客户及当前用户限定。公池客户不出现在新建关联选项中；历史单据在授权范围内保留。

项目级列表的兼容逻辑仍保留搜索、来源、状态及管理员归属筛选，不影响客户工作区的简洁布局；客户工作区不会覆盖项目列表的会话筛选记录。
