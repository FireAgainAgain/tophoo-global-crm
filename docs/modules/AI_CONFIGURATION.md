# AI 配置

位置：系统 → AI 配置。页面名称为“AI 模型连接”，连接按登录用户与当前项目共同隔离，顶部显示项目名称和个人连接、测试通过、业务绑定数量。入口及读写能力由工作区授权和项目角色决定：只读可查看本人的连接摘要，编辑权允许新增、编辑、测试、删除自己的连接；项目管理员也无法读取、修改或调用其他用户的个人连接。

## 当前功能范围

当前没有接入业务 AI 功能，页面收起功能绑定区域，并显示简短说明。保存连接或测试成功不会自动启用 RFQ 整理、标题生成、获客解析等功能；连接可保存备用。获客仍使用现有结构化搜索。

连接列表分别展示连接状态与业务使用情况。显示“允许功能使用”表示连接已通过测试并启用；“尚未用于业务功能”表示没有实际绑定，两者分别说明。

## 添加与编辑

1. 选择服务商，系统带出已有服务商预设地址；模型 ID 以服务商控制台为准，需要自行填写。
2. 填写连接名称、模型 ID、API Key。名称用于识别；密钥不回显，编辑时留空保留原密钥。
3. 地址、温度、最大输出 Token、超时位于高级设置。页面显示当前服务地址，可点击修改；自定义接口自动展开高级设置。
4. 备注用于记录用途、额度到期时间或说明，不发送给模型。

历史连接编辑时保留原地址、模型及参数，根据已知服务地址识别服务商，保存时明确提交服务商字段，修复历史界面未提交服务商导致默认记录为 DeepSeek 的问题。修改地址不会自动替换用户填写的模型 ID。

## 测试与保存

- **仅测试**：检查当前参数，成功后保留本次测试凭证，不保存配置。实际测试会调用服务商接口。
- **保存草稿**：保存完整但无需通过测试的连接，标记停用；不调用服务商。仍需提供名称、模型、地址和密钥，编辑已有连接可保留密钥。
- **测试并保存**：先检查连接，成功后保存并启用；测试失败不保存。
- 已通过测试且连接参数未变时，按钮显示“保存连接”，名称和备注变动不重复调用模型。测试成功后保存失败，重试保存复用本次凭证。
- 修改模型、地址、密钥或高级调用参数后需要重新测试。
- 保存草稿会停用连接，已有业务绑定时会先提示其影响。

失败原因显示在弹窗内，填写内容保留。请求期间阻止重复提交及关闭；支持 Ctrl / ⌘ + S。关闭、切换导航和点击项目行提醒未保存修改，刷新网页使用浏览器离开提醒。外部切换项目会关闭编辑页并重置加载状态，旧响应不能覆盖当前项目。

成功、删除等提示以固定浮层显示，不推移页面。加载失败可直接重试。删除需要确认，有效业务绑定仍需先解除；已退休且不再显示的绑定随连接删除清理。

## 验证

- `python -m pytest tests/test_ai_configuration_flow.py tests/test_ai_configuration_api.py tests/test_structured_prospecting.py -q`：参数测试凭证、保留密钥、服务商和草稿、权限及项目隔离、退休绑定清理、结构化获客保持独立。
- `node tests/ai_config_ui.cjs`：项目范围、空绑定隐藏、服务商识别、草稿、测试与保存失败恢复、保留密钥、未保存提醒、重复提交、手机布局、加载重试、过期响应和删除确认。需要本机 8002 服务、Edge、Playwright；AI 请求全部模拟，阻止其他业务写入，不调用真实服务商。

自动获客当前使用搜索接口、官网读取和规则筛选，不调用模型，无需绑定 AI 连接。模型连接成功不代表自动获客会调用 AI；配置页明确展示此说明。

个人模型使用 crm_user_ai_model_configurations，个人绑定使用 crm_user_ai_feature_bindings。所有读写和测试按 owner_user_id 校验；草稿测试凭证也绑定用户，不能被其他用户复用。旧项目共享表仅保留为历史存档，不自动复制或用于个人请求。请每位用户在当前项目重新填写本人的服务商 Key；当前尚无实际业务 AI 调用。
