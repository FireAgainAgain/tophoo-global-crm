# 报价单

更新：2026-11-02。入口为客户列表中对应客户的报价数量、编号或状态。

客户单据工作区保留刷新、模板管理和新建；搜索、状态统计和常驻筛选隐藏，单页时隐藏分页，手机使用紧凑卡片。状态或编号入口保留可清除的条件提示。Excel 导入及其接口、解析器已移除，报价仍可预览并导出 PDF / Excel。询价单不再提供导出。

### Excel 导出与共用编辑表单（2026-11-01）
- 报价详情增加导出 Excel，与 PDF 并列；导出内容读取本报价单及当前关联客户资料。
- 采用 A4 抬头、五列产品表格、付款及条款布局；联系人、产品、价格、付款标签和银行开关都按报价内容填写，不复制参考文件中的样品数据、备注页和内部计算区域。
- 数量和单价是数值，行金额、总金额、付款及尾款带公式和计算缓存，打开即可显示；账号保留文本格式，防止丢失前导零。用户文本不作为公式执行。
- 包含报价所选 Logo，长规格自动分成续行且不重复数量和金额；打印按 A4 一页宽，长报价可纵向分页。
- Excel 默认以分页预览打开，显示打印页的白色区域、蓝色页边界和打印范围外的灰色背景；保留屏幕网格线，不为工作表外围人为填色。
- 模板编辑与报价编辑使用同一组表单组件、窗口尺寸、Logo 控件和分区。模板管理信息取代报价编号/状态，客户、日期、具体规格和价格在实际报价中填写。
- Excel 空白样式资源位于 `app/resources/quotation/cherry-layout.xlsx`，由 Artifact Tool 生成；服务端按 OpenXML 填充及扩展明细，无需安装 Excel 或启动外部表格运行时。

### 报价模板（2026-10-31）
- 新建报价先选择启用的模板卡片，默认模板优先展示；已有报价编辑直接打开其独立副本。
- 页面右上角模板管理支持新增、复制、编辑、PDF 预览、设为默认、停用及重新启用。模板在当前项目内共享，修改需要报价单写权限。
- 模板保存 Logo、卖方资料、默认币种/单位、付款标签/比例、贸易条款、收款资料及底部联系说明；不保存客户、具体产品、数量、价格或内部备注。
- 支持标准商务及紧凑版式、Logo 显示宽度。可在项目报价模板中填写卖方资料、上传 Logo，并设为默认模板。
- 报价保存模板 ID、名称、版本及版式副本；模板后续编辑、改名、停用不重写旧报价。客户资料依旧实时读取。
- 模板按版本检查并发修改；默认模板不可直接停用，需先将其他启用模板设为默认。模板不提供删除，保留历史归属。
- 模板表沿用数据库默认存储引擎，与现有表保持部署兼容；现有 MyISAM 部署不提供事务回滚保证。

### PDF 参考版式（2026-10-31）
- 按提供的 20260917 PDF 调整为 A4 黑白商务布局：左侧上传标志、右侧公司抬头、双细线、居中 QUOTATION。
- 买方公司、联系人在左侧，日期和报价人在右侧前两行；电话、邮箱及地址行可使用整行宽度，地址较长时自动换行。右侧不显示报价人电话、邮箱，保留抬头和底部联系方式。
- 明细采用固定比例的五列表格，金额汇总与数量、金额列对齐，订金标签加下划线，价格条款保留红色。
- 已保存的体积数据可显示；未填写时不生成体积行。银行和尾款继续按原有开关导出。
- 长文本自动换行，多页重复抬头和明细表头；不修改客户档案或报价内容。
- 买方公司 TO (BUYER) 排在联系人 ATTN 上方。导出标志按可见图案适配，忽略上传图片周围的白色或透明留白。
- 多行规格去除空白行并左对齐，简短型号居中；仅影响 PDF 排版，原始规格和标志数据保留。
- 总金额、订金和可选尾款使用相同金额列并右对齐；报价详情和编辑页面底部恢复 Seller / Buyer 两栏，分别显示当前卖方、买方公司名，并随编辑及关联客户资料同步；底部联系说明继续保留。模板同步显示卖方公司及买方占位说明；实际报价的 PDF / Excel 底部同样显示对应的 Seller / Buyer 公司名称，标签与公司名在同一行，左右两组顶端对齐；长名称在各自公司列内换行。
- 金额汇总增加可编辑的付款标签，例如 FULL PAYMENT；留空沿用原有比例标签。标签随报价保存，详情、预览与导出一致，不改变金额计算。


### 关联资料实时同步（2026-10-31）
- 关联客户后，买方公司、地址以及所选联系人的姓名、电话、邮箱读取当前客户档案；未关联时仍可手动填写。
- 联系人身份保存为报价 JSON 中的 `contact_person_id`，改名或修改邮箱后仍能匹配；旧报价按原邮箱／姓名匹配，无法匹配时使用当前主联系人。
- 进入详情／编辑前重新读取关联选项；停留页面时每 15 秒检查，窗口重新获得焦点时检查。客户及 RFQ 保存通过同页事件和跨标签存储事件通知更新。
- 关联资料同步不重建编辑表单，保留产品、价格、条款、备注和未保存修改。客户更新不会批量改写历史报价 JSON 或报价版本。
- 预览和导出 PDF 同样读取最新关联资料；访问不到关联客户时保留原报价内容，不读取其他归属范围的当前资料。
