# 界面与样式规范

## 配色

主界面支持绿色、蓝色、紫色三种强调色。背景、正文和边框使用一致的中性色，切换配色只改变主操作、选中和聚焦状态。

| 用途 | 约定 |
| --- | --- |
| 主色 | 绿 `#16754f`、蓝 `#2563b9`、紫 `#7151b5` |
| 内容背景 | 白色卡片、浅灰页面 |
| 正文与边框 | 使用主题变量，保证阅读对比度 |
| 业务状态 | 成功绿色、提醒黄色、错误红色，并配文字 |

## 样式入口

主界面只引用三份样式：

1. `workbench.css`：由模块源文件编译，负责页面布局与组件。
2. `ui-themes.css`：自动生成三种强调色，保留业务状态颜色。
3. `appearance.css`：顶部外观面板。

模块源文件与加载顺序在 `app/static/css/workbench.sources.json`。登录、账号、管理页面保留独立样式，不加载整套工作台样式。

## 开发约定

- 修改模块源文件后运行 `python -m scripts.build_frontend`，不要手改生成文件。
- 新模块采用独立类名前缀；加入清单，避免全局 `button`、`table` 等规则影响其他页面。
- 同一组件直接修改现有规则，不新增 `fix`、`v2`、`polish` 版本文件；模板中不添加内嵌样式块。
- 布局和状态样式分别处理，减少 `!important` 和重复覆盖；动态业务状态类需同步检查。
- 导航收缩避免对宽度、边距逐帧动画；弹窗和提示优先使用轻量位移、透明度反馈，并支持 `prefers-reduced-motion`。
- 提示不占列表布局空间；表格随数据自然收缩，目录采用紧凑标题、图标与缩进。

构建检查：`python -m scripts.build_frontend --check`。母版导出见 [新项目母版](../PROJECT_TEMPLATE.md)。
